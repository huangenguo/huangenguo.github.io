## 四、教育机构采购的特殊渠道与建议

### 1. 直接联系源头厂家（最省钱、最推荐）

对于无人机足球、STEAM教具这类**专业品类**，最好的方式是**跳过平台直接联系厂家**：

- 聚森智能（无人机足球）：135 0002 0705 / <https://www.jusenmodel.com/>
- 百邦源（低价空心杯）：151 1809 9846（微信）
- 乐迪（竞赛级）：官网 <https://www.radiolink.com.cn/>
- 雷迪安（教学级）：官网 <https://www.ldarc.com/>
- 阿派斯教育照搬小鸟飞飞 | 航空科普教育: <http://www.fii-edu.com/Index.aspx>
- 广东超优航空科技有限公司: <https://www.aopacn.com/>

**优势**：批量折扣大、可贴牌定制、可要求配套课程资料、售后直接对接技术。

### 2. 教育装备采购平台/政采渠道

如果学校需要走**对公采购/招投标**流程：

- 中国教育装备采购网
- 各省市政府采购网
- 学校通常有定点供应商或教育装备展渠道

### 3. 行业展会（现场对接厂家）

| 展会             | 时间/地点    | 说明                      |
| -------------- | -------- | ----------------------- |
| 中国澄海国际玩具礼品博览会  | 每年4月，澄海  | 澄海本地最大玩具展，几千厂家参展        |
| 广州国际玩具及模型展     | 每年4月，广州  | 华南最大玩具展                 |
| 中国国际玩具及教育设备展览会 | 每年10月，上海 | 全国最大，教育玩具品类集中           |
| 中国教育装备展示会      | 每年春秋两届   | 教育装备专业展，STEAM/无人机教具厂家集中 |

### 4. 澄海本地采购一日游路线建议

如果你想实地采购，推荐这条路线：

1. **上午**：宝奥国际玩具城（金鸿公路）— 最大最全，先看整体市场
2. **中午**：在澄海城区吃饭
3. **下午第一站**：宏腾玩具展厅/霄鸟云（文冠路优必选大厦）— 线上线下联动选品
4. **下午第二站**：澄海塑料城（国道324线）— 老牌市场找低价
5. **如果有明确目标**：直接去厂家看厂（如聚森在澄华街道下窖工业区）
