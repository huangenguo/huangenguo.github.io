八合一加密狗本质是把接收机的 **PPM 模拟信号** 转成 USB 游戏控制器，它的兼容模式是固定写死的（G3/G4/Phoenix/XTR 等老模拟器模式），穿越机模拟器（Liftoff / Velocidrone / DRL）走的是标准 HID 手柄协议，八合一经常识别异常或通道映射错乱。

下面按**推荐优先级**给你 5 套方案，从零成本到低成本都有：

---

## 方案一：SBUS 转 USB 专用模块（最推荐，成本约 20–40 元）

这是换掉八合一加密狗最直接的升级，也是航模圈目前最稳的模拟器接入方式。

**原理**：用你现有的 FS-iA6B / iA10B 接收机的 **SBUS 数字输出**，接一个 SBUS 转 USB 模块（淘宝搜"SBUS转USB 模拟器"），模块另一端 USB 插电脑。

**优势**：

- 数字信号，不像 PPM 那样有通道漂移和延迟
- 标准 HID 手柄协议，**Liftoff / Velocidrone / DRL / Phoenix 全兼容**
- 支持最多 16 通道（八合一通常只有 6–8 通道）
- 即插即用，Windows 自动识别，不需要装驱动

**接线**：接收机 SBUS 引脚 → 模块 SBUS 引脚，模块供电走 USB，接收机单独供电（可以插飞控 BEC 或单独 5V 电源）。

---

## 方案二：vJoy + FreePIE 软件映射（零成本，盘活现有加密狗）

如果你不想再花钱买硬件，可以用软件把八合一加密狗的输入"翻译"成模拟器能认的虚拟手柄。

**原理**：八合一加密狗在 Windows 里其实是能被识别为输入设备的（控制面板→设备和打印机里能看到），只是穿越机模拟器不认它的通道格式。用 vJoy 创建一个虚拟 Xbox/手柄，再用 FreePIE 写脚本把加密狗的轴数据映射过去。

**八合一加密狗 = 说方言的人**
**FreePIE = 翻译**
**vJoy = 标准普通话话筒，模拟器听得懂**

**操作步骤**：

1. 安装 **vJoy**（虚拟游戏控制器驱动，开源免费）
2. 安装 **FreePIE**（输入重定向软件，开源免费）
3. 写一个简单脚本，读取加密狗的 X/Y/Z/Rz 轴，输出到 vJoy 的虚拟轴
4. 模拟器里选择"vJoy Device"作为控制器

**缺点**：设置稍复杂，有 5–10ms 额外延迟（练穿越机基本感知不到），脚本需要根据你的通道映射微调。

> 如果你选这个方案，我可以直接给你写好 FreePIE 脚本，你改一下通道编号就能用。

## 方案三：刷 FS-i6 修改版固件，启用 USB 直连（零成本，需动手）

很多人不知道：FS-i6 背后那个 Mini USB 口**原生不支持**模拟器（只能升级固件和当教练口），但刷了民间修改版固件后，可以解锁 **USB HID 游戏控制器**功能。

**操作**：

1. 确认你的 FS-i6 硬件版本（老版 i6 用 STM32F103C8T6，可刷）
2. 刷入"FS-i6 10通道修改固件"（圈内流传很广，支持 USB 模拟器模式）
3. 刷完后用 Mini USB 数据线直连电脑，遥控器开机自动识别为游戏控制器
4. 不需要接收机、不需要加密狗、不需要电池（USB 供电）

**风险**：刷机有刷砖概率，需要严格按教程操作，刷之前备份原固件。如果你的 i6 是比较新的批次（主板改版），可能不兼容修改固件。

---

## 方案四：换一个高兼容加密狗（成本约 30–80 元）

如果不想折腾软件和刷机，直接把八合一换成**专门标注支持 Liftoff/Velocidrone 的加密狗**。

**选购要点**：

- 搜"22合1 模拟器加密狗"或"穿越机模拟器加密狗"
- 商品描述里**明确写了支持 Liftoff / Velocidrone / DRL**
- 优先选带 SBUS 输入的（比纯 PPM 的稳）
- 避免买那种只有 PPM 输入、只标"支持 G3/G4/Phoenix"的老款

---

## 方案五：换遥控器（成本较高，一劳永逸）

如果后续长期玩模拟器，预算允许的话，换一个**原生 USB 模拟器支持**的遥控器是最省心的：

- **富斯 FS-i6X**（i6 的升级版，原生 USB 直连，约 300 元）
- **Radiomaster TX12 / TX16S**（开源 EdgeTX，USB 即插即用，约 500–1000 元）
- **乐迪 AT9S Pro**（约 400 元）

这些遥控器 USB 线一插，所有模拟器直接识别，不需要任何加密狗、接收机、映射软件。

---

## 方案六：USB‑TTL 接【接收机 IBUS】，搭配 vJoySerialFeeder + vJoy

> FS‑i6遥控器 无线 → iA6B接收机 IBUS输出 → USB‑TTL模块RX ↔ GND →电脑COM口

1. FS‑i6遥控器 烧录固件，开启 ibus PWM 输出
2. CH340 USB‑TTL 模块
3. iA6B 接收机，开启 IBUS 输出 [iA6B IBUS 接线图](https://www.bilibili.com/video/BV1JG411d7jP?comment_on=1&comment_root_id=271028672112&share_tag=s_i#reply271028672112) 接线：接收机 IBUS → USB‑TTL **RX**；接收机 GND → USB‑TTL GND；接收机 5V 供电
4. 软件：**vJoy + vJoySerialFeeder** vJoySerialFeeder软件（解析IBUS串口数据） →写入vJoy虚拟手柄 → Liftoff模拟器读取vJoy

[Cleric-K/vJoySerialFeeder: Feed Virtual Joystick driver with data from a serial port](https://github.com/Cleric-K/vJoySerialFeeder)

[vJoy - Browse /Beta 2.x at SourceForge.net](https://sourceforge.net/projects/vjoystick/files/Beta%202.x/)

## 总结对比

|方案|硬件|软件|特点|
|---|---|---|---|
|八合一加密狗 + FreePIE+vJoy|八合一加密狗 + iA6B|FreePIE+vJoy|PPM模拟信号，容易漂移，你现在手里这套|
|USB‑TTL接接收机IBUS + vJoySerialFeeder+vJoy|CH340 TTL +iA6B|vJoySerialFeeder +vJoy|数字IBUS，无线，TTL廉价，需要常驻软件|
|SBUS转USB硬件模块|SBUS转USB模块 +iA6B|无软件，HID即插即用|⭐最优，不需要后台软件，低延迟，20‑40元|
|刷i6修改固件|miniUSB数据线|无软件，HID直连|遥控器刷机，有砖机风险，丢掉接收机|
